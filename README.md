# SmartStyle Demo

A responsive fashion-discovery dashboard built with **React, TypeScript, Vite, and Tailwind CSS**, similar in structure to a modern shopping and style-assistant web app.

## Features
- Responsive sidebar navigation
- Discover landing page and promotional hero section
- Product cards with images, categories, and prices
- Search and category filtering
- Save/unsave products
- Add-to-bag interaction with item count and confirmation toast
- Style assistant panel

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

Images are loaded from Unsplash and therefore require an internet connection to display.
